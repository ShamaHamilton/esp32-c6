## Модульная структура проекта

Код разделен по принципу единой ответственности (Separation of Concerns) на пакет `power_calc` и входной скрипт `main.py`:
```Plaintext
esp32_power_calc/
├── main.py                  # Точка входа для быстрого запуска (python3 main.py)
└── power_calc/              # Основной пакет калькулятора
    ├── __init__.py          # Инициализация пакета и экспорт ключевых сущностей
    ├── models.py            # Датаклассы физической модели (АКБ, обвязка платы, АЦП, режимы сна, результаты)
    ├── presets.py           # База предустановок ESP32-C6 SuperMini и сценариев (Offline, BLE, Zigbee, Wi-Fi)
    ├── engine.py            # Математическое ядро расчета (токи, заряды циклов, безубыточность, автономность)
    ├── formatter.py         # Табличный движок с поддержкой ANSI-цветов, гистограммы и экспорт в Markdown
    └── cli.py               # Парсер аргументов командной строки (argparse) и сборка пайплайна
```

# Краткая инструкция по использованию настроенной среды

## 1. Подключение платы
Плата подключается по USB к Windows. Устройство прокидывается в WSL через `usbipd`.

В WSL должно появиться: `/dev/ttyACM0` (ESP USB JTAG/serial).

## 2. Активация окружения
В любом терминале zsh:
```bash
get_idf
# или
. ~/.esp/esp-idf/export.sh
```
После этого доступны `idf.py`, `esptool.py`, `xtensa-esp*/riscv32-esp-*` инструменты.

## 3. Работа с проектом
```bash
cd ~/Projects/esp32/C6_SuperMini
idf.py build        # Сборка
idf.py -p /dev/ttyACM0 flash  # Прошивка
idf.py -p /dev/ttyACM0 monitor # Монитор порта (Ctrl+] для выхода)
idf.py menuconfig   # Конфигурация
idf.py fullclean    # Полная очистка
```

## 4. VSCode
1. Открыть папку `~/Projects/esp32/C6_SuperMini` в VSCode
2. Установлено расширение `espressif.esp-idf-extension` (уже в списке расширений)
3. Настройки в `.vscode/` применятся автоматически
4. Через `Terminal > Run Task` доступны IDF-задачи

## 5. Если устройство ушло в USB_BOOT
После прошивки или неправильного сброса чип может остаться в режиме загрузки.
1. Отключить USB **без зажатого BOOT**
2. Подключить обратно **без BOOT**
3. В WSL прокинуть устройство (если нужно): `usbipd attach --wsl --busid X-Y`

## 6. JTAG отладка
Доступен OpenOCD: `/tmp/opencode/openocd/openocd-esp32/bin/openocd`
Конфиги: `interface/esp_usb_jtag.cfg`, `target/esp32c6.cfg`

## 7. Важные пути
| Путь | Назначение |
|---|---|
| `~/.esp/esp-idf/` | ESP-IDF v6.1 |
| `~/.esp/espressif/` | Тулчейны, Python venv, кэши |
| `~/Projects/esp32/C6_SuperMini/` | Текущий проект |
| `/dev/ttyACM0` | Последовательный порт платы |

## 10. Тесты
Тесты перенесены в `tests/`. Пример `tests/pytest_hello_world.py` требует `pytest-embedded`. Для старта можно просто тестировать через `idf.py flash monitor`. См. [Архитектура, память, тесты](АРХИТЕКТУРА_ПАМЯТЬ_ТЕСТЫ.md).

## 11. Тестирование с pytest (виртуальное окружение)
В проекте есть локальное venv: `.venv/`

```bash
cd ~/Projects/esp32/C6_SuperMini
source .venv/bin/activate
get_idf  # активировать ESP-IDF окружение (нужно для инструментов)
pytest tests/pytest_hello_world.py --target esp32c6 -p esp-idf 2>&1 | tail -60
deactivate
```

Тесты запускаются на реальной плате (или QEMU). Порт определяется pytest-embedded.

# Тестирование в ESP-IDF проекте (пошагово)

## 1. Установка окружения для тестов
В проекте есть локальное venv: `.venv/`

```bash
cd ~/Projects/esp32/C6_SuperMini
python3 -m venv .venv  # или virtualenv (уже создано)
source .venv/bin/activate
pip install pytest pytest-embedded pytest-embedded-idf pytest-embedded-serial-esp
deactivate
```

## 2. Структура тестов
- Тесты размещаем в `tests/` 
- Файлы `pytest_*.py` или `test_*.py`
- Можно использовать `conftest.py` для общих фикстур

## 3. Запуск тестов на реальной плате
```bash
cd ~/Projects/esp32/C6_SuperMini
source .venv/bin/activate
get_idf
# Убедиться что плата подключена (/dev/ttyACM0)
idf.py build  # собрать перед тестом
pytest tests/pytest_hello_world.py --target esp32c6
deactivate
```

## 4. Простой тест для своего примера
Создаём `tests/test_blink.py`:
```python
import pytest
from pytest_embedded_idf.dut import IdfDut

@pytest.mark.generic
def test_blink_runs(dut: IdfDut):
    # Ожидаем какой-то лог из нашего приложения
    dut.expect("LED", timeout=10)
```

Запуск:
```bash
pytest tests/test_blink.py --target esp32c6
```

## 5. Полезные советы
- Тесты `hello_world` из примера рассчитаны на полный набор окружения pytest-embedded. Для своих тестов проще писать минимальные.
- Всегда сначала `idf.py build`
- Плата должна быть в нормальном режиме (не USB_BOOT)
- Если тесты долго висят - проверить подключение через `idf.py monitor`
